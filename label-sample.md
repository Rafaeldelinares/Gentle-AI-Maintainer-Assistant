## Cómo usar esta lista

1. Abrí el tablero (`python3 board/server.py --port 8770`) y copiá cada `ref` en el buscador.
2. Leé el issue en GitHub (botón «abrir en GitHub ↗») y elegí un **veredicto humano**.
3. Escribí una nota si el motor se equivocó. La nota es el dato más útil del log.
4. Cuando tengas suficientes, corré `python3 tools/precision_report.py --write`.

**No hay que hacer los 120 de una sentada.** Con 40 etiquetas que cubran P0/P1
ya se pueden ver los falsos negativos; la precisión por regla necesita más.
